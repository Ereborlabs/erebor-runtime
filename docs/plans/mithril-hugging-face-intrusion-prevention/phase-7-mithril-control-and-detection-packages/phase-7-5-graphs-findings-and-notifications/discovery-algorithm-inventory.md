# Discovery Engine algorithm inventory

All entries use source revision `0b5b73425c5aec89b803e737b188b2a331d0e218`.
They inherit the datasets, host checks, bounds, execution targets, later owner,
and status in [the contract inventory](discovery-contract-inventory.md).
Each ID identifies a computation requirement. The proposed export name gives
a descriptor mapping. A later package can combine these computations and share
helper implementations. Source tests are references, not port qualification.
