# Discovery Engine input and delegated computation inventory

All entries use source revision `0b5b73425c5aec89b803e737b188b2a331d0e218`.
They inherit the datasets, host checks, bounds, execution targets, later owner,
and status in [the contract inventory](discovery-contract-inventory.md).
Each ID identifies a computation requirement. The proposed export name gives
a descriptor mapping. A later package can combine these computations and share
helper implementations. Source tests are references, not port qualification.

## Recorded input, converters, and delegated computation

The converter files are under [plugin](https://github.com/accuknox/discovery-engine/tree/0b5b73425c5aec89b803e737b188b2a331d0e218/src/plugin),
[analyzer](https://github.com/accuknox/discovery-engine/tree/0b5b73425c5aec89b803e737b188b2a331d0e218/src/analyzer),
[cluster](https://github.com/accuknox/discovery-engine/tree/0b5b73425c5aec89b803e737b188b2a331d0e218/src/cluster),
[feedconsumer](https://github.com/accuknox/discovery-engine/tree/0b5b73425c5aec89b803e737b188b2a331d0e218/src/feedconsumer),
and [libs](https://github.com/accuknox/discovery-engine/tree/0b5b73425c5aec89b803e737b188b2a331d0e218/src/libs).
Database SQL is part of this audit when it selects, groups, counts, or changes
the meaning of data. A database connection is not a package dependency.

Database insert/update routines for candidates, resource sets, and policy YAML
also encode latest/outdated links, resource-set keys, labels, and timestamps.
The port uses DE05 and the shared datasets for these values. It does not hide
candidate merge or resource-set construction inside a database writer.
`ClearWPFSDb`, `ClearSysDb`, `ClearNetworkDB`, `ClearDBTables`,
`ClearNetworkDBTable`, `PurgeOldDBEntriesCronJob`, and their MySQL/SQLite
variants are host retention operations. The host must supply an explicit time
window and input revision after retention. A package does not delete its inputs.
